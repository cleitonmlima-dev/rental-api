# Instruções do projeto

## Regra padrão de desenvolvimento

Todo desenvolvimento neste projeto deve gerar uma nova ADR acompanhada da spec correspondente. Essa exigência se aplica a funcionalidades, correções, refatorações, testes, configuração, infraestrutura e documentação.

Criar a ADR e criar ou atualizar a spec antes da implementação. Entregar a mudança com os dois documentos vinculados entre si e atualizados conforme o resultado final.

Seguir os formatos, locais e critérios de conclusão definidos na [regra de ADR e spec obrigatórias](docs/especificacao-tecnica.md#15-adrs-e-specs-obrigatórias).
